# Compatibility UI

The HTML application in this directory is deprecated. The React application under `web/src` is the primary LumaForge UI.

Do not add new product features here. Changes are limited to migration compatibility, packaged desktop maintenance, security fixes, and release-critical recovery paths.

These files remain temporarily because the desktop launcher, updater, application settings, and legacy data import still depend on them. See `docs/LEGACY_MIGRATION_AUDIT.md` for the removal gates.
